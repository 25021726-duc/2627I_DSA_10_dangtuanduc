# Stack & Queue exercises

Bốn lời giải Java cho các bài HackerRank trong nhóm bài tập stack và queue:

1. `BalancedBrackets.java`
2. `QueueUsingTwoStacks.java`
3. `SimpleTextEditor.java`
4. `EqualStacks.java`

Mỗi file là một chương trình độc lập, nhận input từ standard input và in kết quả ra
standard output theo đúng định dạng HackerRank.

## Biên dịch

```bash
javac BalancedBrackets.java QueueUsingTwoStacks.java SimpleTextEditor.java EqualStacks.java
```

## Chạy

Ví dụ:

```bash
java BalancedBrackets < input.txt
```

Khi nộp riêng từng bài trên HackerRank, đổi tên public class của bài đó thành
`Solution` nếu trình chấm yêu cầu.
